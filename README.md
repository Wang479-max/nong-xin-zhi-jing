# 农芯智境 - 智慧农业数字孪生管理系统

> 中国大学生计算机设计大赛（4C）·「软件应用与开发 / Web 应用与开发」赛道作品

面向智慧农业的 **「宏观—地块—单株—器官」四级数字孪生** Web 管理系统：以 Cesium 宏观地理底座 + **纯代码 Three.js 微观孪生体** 为核心，打通 IoT 实时数据与三维可视化，融合多模态 AI（病害识别、种植决策、知识问答），形成「监测—诊断—决策—执行」业务闭环。前后端分离，后端 Express + WebSocket，前端 React 19 + Three.js / Cesium。

## ✨ 核心亮点

- **纯代码农业微观数字孪生**：农艺参数级分器官建模（根/茎/叶/穗）+ L-system 分形根系 + 全着色器风场/生长/倒伏物理 + 程序化叶脉/次表面散射/病斑，零外部模型与贴图。
- **实例化高性能渲染**：`InstancedMesh` + LOD + 视锥裁剪，单地块 ≥1000 株、千株场景 ≥45 FPS。
- **数据闭环**：IoT/JSON 数据双向绑定，墒情/养分/病害驱动形态与材质实时变化；产量预估、框选区域聚合统计。
- **可复现**：确定性随机种子，同参数生成完全一致田块，结果可验证。
- **工程化**：安全响应头 + 接口限流 + 集中式异常处理 + 进程级崩溃兜底 + 优雅关闭 + 容器化部署。

## 在地运行配置

为了确保系统能够正常运行 AI 识别与诊断功能，请完成以下环境变量配置：

1. 在项目根目录下复制 `.env.example` 为 `.env`。
2. 打开 `.env` 文件，填入您的真实 API Key：
   ```env
   # 确保替换为真实的 Key，不要包含引号
   QWEN_API_KEY=sk-...
   ZHIPU_AI_KEY=...
   ```
3. 运行环境设置：
   - 确保安装了 Node.js (建议 18.x 或更高版本)。
   - 安装依赖: `npm install`。
   - 启动开发服务: `npm run dev`。

## 构建与生产部署

1. **构建前端与后端**：
   ```bash
   npm run build
   ```
   构建产物将生成在 `dist/` 目录下（前端静态资源 + `server.cjs`）。

2. **以生产模式启动**：
   ```bash
   npm start
   ```
   服务默认监听 `http://localhost:3000`。

3. **类型检查（可选）**：
   ```bash
   npm run lint
   ```

## 🐳 Docker 容器化部署（推荐）

## 3D 农田孪生视图优化

为了提供逼真的视觉体验，系统对 Three.js 近景视图进行了深度优化：
- **全景视野**: 自动根据地块数量调整摄像机焦距与高度，确保多地块布局下所有土地均完整可见。
- **环境拟真**: 增加了远山背景、防护林带、大气雾效以及动态光影，提升了数字孪生的真实感。
- **中文交互**: 所有的 3D 悬浮标签、HUD 界面及系统提示均已完全汉化。
