# 安全与健壮性设计

> 对应 4C 评审「**技**-安全防护与异常处理」「**健**-内容合规、系统健壮性与稳定性」。

## 一、安全体系

### 1.1 安全响应头（全局中间件）

所有响应统一注入安全头（`server.ts` 请求中间件）：

| 响应头 | 取值 | 作用 |
| :-- | :-- | :-- |
| `X-Content-Type-Options` | `nosniff` | 禁止 MIME 类型嗅探 |
| `X-Frame-Options` | `SAMEORIGIN` | 防点击劫持（禁止被第三方 iframe 嵌入）|
| `Content-Security-Policy` | `frame-ancestors 'self'; object-src 'none'; base-uri 'self'` | 限制嵌入源、禁用插件对象、锁定 base 标签 |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | 防跨域 Referer 信息泄露 |
| `X-XSS-Protection` | `1; mode=block` | 旧版浏览器 XSS 过滤 |
| `Permissions-Policy` | 限定 geolocation/mic/camera 为同源 | 最小权限 |
| `Strict-Transport-Security` | HTTPS 下 `max-age=15552000` | 强制 HTTPS |

> 说明：CSP 仅启用不影响脚本/样式/Worker/WASM 加载的指令，以兼容 Cesium、Three.js Worker 与 Vite，避免「为安全而瘫痪功能」。

### 1.2 接口限流（防刷量 / DoS）

- 内存级**滑动窗口**限流器，按客户端 IP（支持 `X-Forwarded-For`）统计。
- 默认每 IP **1200 次/分钟**（可经 `RATE_LIMIT_PER_MIN` 环境变量调整）。
- 超限返回 `429` + `Retry-After`，并回传 `X-RateLimit-Limit / X-RateLimit-Remaining`。
- `/api/health` 豁免限流，保证健康探针可用。
- 过期窗口定时清理，避免内存增长。

### 1.3 鉴权与权限

- 登录注册接口 `/api/auth/*`，用户态贯穿业务接口（按 `owner` 隔离地块等资源）。
- 支持账户安全增强：密码修改、二次验证（2FA）开关 `/api/user/security/*`。
- 设备控制、数据写入类接口绑定用户上下文，防越权访问他人资源。

### 1.4 输入与传输

- `express.json` / `urlencoded` 限制请求体大小，防超大 payload 攻击（图像上传场景单独放宽）。
- 前端 React 默认对渲染内容转义，降低存储型/反射型 XSS 风险。
- 所有外部 AI/资讯调用包裹超时与异常捕获，失败降级而非阻塞。

### 1.5 敏感信息管理

- API Key 经 `.env` 注入（`dotenv`），`.env` 已纳入 `.gitignore`，仅提供 `.env.example` 模板。
- **安全建议（生产部署须执行）**：移除 `server.ts` 中的 Key 兜底默认值，统一改为从环境变量读取并在缺失时显式告警；密钥经密钥管理服务或部署平台环境变量下发，严禁入库。

## 二、健壮性与稳定性

### 2.1 集中式异常处理

- 统一的 4-arg Express 错误处理中间件：捕获路由异常，**不泄露堆栈**，返回标准化错误体 `{ success:false, error, code }`。
- `/api/*` 未命中路由返回 JSON 404，避免被 SPA catch-all 返回 HTML 误导前端。

### 2.2 进程级崩溃兜底

- `uncaughtException` / `unhandledRejection` 全局捕获并记录日志，**进程不退出**，保障长时间演示稳定。
- 端口被占用（`EADDRINUSE`）自动改用系统空闲端口，避免启动崩溃。

### 2.3 优雅关闭

- 监听 `SIGTERM` / `SIGINT`：先关闭所有 WebSocket 连接，再关闭 HTTP 服务并退出；5s 兜底强制退出，保证端口与连接干净释放（容器编排友好）。

### 2.4 数据持久化健壮性

- 文件型 JSON 库读写带**重试 + 锁文件（sync.lock）+ 回退**机制，避免并发写入损坏。

### 2.5 性能与可观测

- `/api/health` 输出 uptime、Node 版本、RSS/堆内存、WebSocket 连接数，便于巡检与压测监控。
- 慢接口（>800ms）自动落 `[Perf]` 日志，便于定位优化点。
- AI 结果 24h 缓存（带版本号），降低重复算力开销与响应时延。

## 三、安全自测结论

| 项 | 结论 |
| :-- | :-- |
| 点击劫持 | 已通过 `X-Frame-Options` + CSP `frame-ancestors` 防护 |
| MIME 嗅探 | 已通过 `nosniff` 防护 |
| 接口刷量 | 已通过 IP 限流防护，超限返回 429 |
| 异常输入 | 集中式异常处理兜底，返回标准化错误，不崩溃 |
| 越权访问 | 资源按用户隔离 |
| 密钥泄露 | `.env` 管理 + `.gitignore`（生产须移除源码兜底默认值）|
