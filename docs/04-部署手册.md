# 部署手册

> 对应 4C 评审「**技**-容器化部署、环境一致性」「文档与提交规范」。

## 一、环境要求

| 项 | 要求 |
| :-- | :-- |
| Node.js | 18.x 及以上 |
| 操作系统 | Windows / Linux / macOS（生产推荐 Linux）|
| 浏览器 | Chrome / Edge / Firefox 最新版 |
| 端口 | 默认 3000（被占用时自动切换空闲端口）|

## 二、本地开发运行

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量（复制模板后填入真实 Key）
cp .env.example .env
#   QWEN_API_KEY=sk-...
#   ZHIPU_AI_KEY=...
#   RATE_LIMIT_PER_MIN=1200   # 可选：接口限流阈值

# 3. 启动开发服务（前端 Vite 中间件 + 后端 Express 同进程）
npm run dev
# 访问 http://localhost:3000
```

## 三、生产构建与启动

```bash
# 构建前端静态资源 + 打包后端为 dist/server.cjs
npm run build

# 以生产模式启动
NODE_ENV=production npm start
# 服务监听 http://0.0.0.0:3000
```

类型检查（提交前质量门禁）：

```bash
npm run lint      # tsc --noEmit，零错误方可提交
```

## 四、Docker 容器化部署（推荐）

项目根目录已提供 `Dockerfile`、`docker-compose.yml`、`.dockerignore`，保证环境一致性与快速迁移。

### 4.1 使用 Docker Compose（一键）

```bash
# 在 .env 中配置好密钥后：
docker compose up -d --build

# 查看日志
docker compose logs -f

# 健康检查
curl http://localhost:3000/api/health

# 停止
docker compose down
```

### 4.2 使用纯 Docker

```bash
docker build -t nong-xin-zhi-jing .
docker run -d --name nxzj -p 3000:3000 \
  -e QWEN_API_KEY=sk-xxx -e ZHIPU_AI_KEY=xxx \
  -v $(pwd)/.data:/app/.data \
  nong-xin-zhi-jing
```

> 数据卷 `.data` 持久化文件型数据库，容器重建不丢数据。

## 五、公网访问与反向代理

生产环境建议置于 Nginx / Caddy 反向代理之后，统一启用 HTTPS（系统检测到 HTTPS 会自动下发 HSTS 头），并将 `X-Forwarded-For`、`X-Forwarded-Proto` 透传给应用以便正确限流与协议识别。

Nginx 关键片段：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    # WebSocket 升级（实时监测推送）
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
}
```

## 六、运维与排障

| 现象 | 排查 |
| :-- | :-- |
| 启动报端口占用 | 已自动切换空闲端口；查看日志获取实际端口 |
| AI 功能不可用 | 检查 `.env` 中 `QWEN_API_KEY` / `ZHIPU_AI_KEY` 是否有效 |
| 接口返回 429 | 触发限流，调高 `RATE_LIMIT_PER_MIN` 或排查异常刷量 |
| 健康/巡检 | `GET /api/health` 查看 uptime、内存、WS 连接数 |
| 慢接口定位 | 查看服务端 `[Perf]` 慢接口日志（>800ms）|
| 数据未持久化 | 确认 `.data` 目录可写且已挂载为数据卷 |
