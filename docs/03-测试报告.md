## 三、接口与健康检查

```bash
$ curl -D - http://localhost:3000/api/health
HTTP/1.1 200 OK
X-Content-Type-Options: nosniff
X-Frame-Options: SAMEORIGIN
Content-Security-Policy: frame-ancestors 'self'; object-src 'none'; base-uri 'self'
...
{"status":"ok","uptimeSec":9,"version":"1.0.0","node":"v...","memoryMB":{"rss":178,"heapUsed":54},"ws":0}

$ curl http://localhost:3000/api/不存在的接口
{"success":false,"error":"...","code":"NOT_FOUND"}   # 统一 JSON 404
```

- 安全响应头随所有响应返回 ✅
- 未命中 `/api` 路由返回 JSON 404 ✅
- 异常请求经集中式错误处理返回标准化错误体、服务不崩溃 ✅

## 四、性能测试

| 指标 | 方法 | 结果 |

## 七、边界与异常场景

| 场景 | 处理 |
| :-- | :-- |
| 网络波动 / AI 超时 | 超时捕获 + 降级提示，不阻塞 |
| 端口被占用 | 自动改用空闲端口 |
| 数据文件并发写 | 重试 + 锁 + 回退 |
| 未处理异常/Promise | 进程级兜底，记录日志不退出 |
| 进程收到终止信号 | 优雅关闭释放连接与端口 |
