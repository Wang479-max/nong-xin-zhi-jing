## 一句话简介

**农芯智境** 是面向智慧农业的「**宏观—地块—单株—器官**」四级数字孪生管理系统：以 Cesium 宏观地理底座 + 纯代码 Three.js 微观孪生体为核心，打通 IoT 实时数据与三维可视化，融合多模态 AI（病害识别、种植决策、知识问答），形成「监测—诊断—决策—执行」业务闭环。

## 核心亮点（对应 4C「创量健技美」）

- **创**：纯代码程序化农业微观数字孪生（农艺参数级建模 + L-system 根系 + 生长/风场/倒伏物理着色器），填补宏观地块与单株器官之间的可视化断层。
- **量**：30+ 后端接口、23 个前端功能模块，覆盖监测、孪生、AI、知识库、资讯、运维全链路。
- **健**：安全响应头 + IP 限流 + 集中式异常处理 + 进程级崩溃兜底 + 优雅关闭，长时间运行稳定。
- **技**：前后端分离、实例化渲染（InstancedMesh）+ LOD + 视锥裁剪、WebSocket 实时推送、多模型 AI 编排与缓存。
- **美**：统一的深色科技 HUD 设计语言、流畅 3D 交互、数据可视化大屏。
